IntelliJ Spring Boot Demo
========================

Requirements:
- Java 17
- IntelliJ IDEA

Run:
1. Open this folder in IntelliJ IDEA.
2. Wait for Maven dependencies to download.
3. Open IntellijSpringbootDemoApplication.java.
4. Click the green Run button next to main().
5. Open http://localhost:8080/hello

Expected output:
Hello Spring Boot from IntelliJ!
